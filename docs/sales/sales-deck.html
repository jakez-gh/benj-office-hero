Trust & Compliance

Enterprise-grade security. Small-business price.

🔐
Tenant Isolation
PostgreSQL row-level security enforces hard data boundaries. No tenant can ever read another tenant's records — even at the DB layer. Defense-in-depth at service layer too.
🛡️
JWT RS256 Auth + RBAC
15-minute access tokens, 7-day refresh. Eight predefined roles with fine-grained permission overrides per user. Every endpoint declares the minimum role and permission required.
📋
Immutable Audit Log
Every auth event, permission denial, data access, and admin action is appended to an append-only audit log. DB triggers prevent modification. Operator search and export available.
⚡
Rate Limiting
All endpoints rate-limited by tier: auth (10 req/min/IP), writes (60/min/user), reads (300/min/user). Operators adjust limits live without restart. DDoS basic mitigation built in.
🔍
Continuous CVE Scanning
pip-audit runs four times daily (06:00, 12:00, 18:00, 00:00 UTC). Critical vulnerabilities trigger immediate alerts. Bandit static analysis on every push.
☁️
99.5% Uptime SLO
Fly.io cloud hosting with health checks, Sentry error tracking, and hourly uptime monitoring. Structured JSON logs shipped to Grafana. HTTPS enforced; HTTP redirected.
